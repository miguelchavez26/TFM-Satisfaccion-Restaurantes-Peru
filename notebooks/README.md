# Notebook del proyecto

Esta carpeta contiene el notebook principal utilizado para el desarrollo del Trabajo Fin de Máster.

## Archivo principal

**TFM_RestaurantesV1.ipynb**

El notebook contiene el desarrollo completo del proyecto, incluyendo las siguientes etapas:

- Preparación y tratamiento de los datos.
- Análisis exploratorio.
- Procesamiento y normalización de las reseñas.
- Análisis de palabras, bigramas y trigramas.
- Análisis de sentimiento mediante PySentimiento.
- Preparación de variables mediante TF-IDF.
- Construcción y evaluación de modelos de Machine Learning.
- Análisis de aspectos de la experiencia gastronómica.
- Optimización y selección del modelo final.
- Sistema de recomendación de restaurantes.
- Dashboard de satisfacción gastronómica.
- Auditorías y validaciones finales.
- Preparación de resultados para la exportación HTML.

## Entorno de desarrollo

El proyecto fue desarrollado principalmente en **Google Colab utilizando Python**.

El notebook representa el código principal del proyecto y contiene tanto las etapas de procesamiento como los resultados obtenidos durante su ejecución.

## Nota sobre la ejecución

La reproducción completa del notebook requiere disponer previamente de los archivos del dataset utilizados durante el proyecto.

La procedencia de estos datos y las instrucciones generales para obtenerlos se encuentran documentadas en la carpeta `datos/`.
