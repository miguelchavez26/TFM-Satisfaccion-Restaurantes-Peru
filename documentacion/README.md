# Documentación del proyecto

- Metodología de desarrollo.
- Preparación y análisis de los datos.
- Análisis de sentimiento y aspectos.
- Modelización y comparación de alternativas.
- Optimización y selección del modelo final.
- Resultados e interpretación de negocio.
- Sistema de recomendación de restaurantes.
- Dashboard de satisfacción gastronómica.
- Aplicación empresarial.
- Conclusiones.
